## Architecture Notes
- The admin panel uses custom session-based auth (Middleware: `AdminAuth`), NOT standard Laravel Breeze/Jetstream.
- Images are stored locally using the `public` disk. When moving to Supabase/Vercel, the `FILESYSTEM_DISK` must be updated to S3 or equivalent, as serverless platforms have ephemeral file systems.
- The UI follows a strict dark theme with gold accents and premium glassmorphism effects. Ensure all new admin pages match the styling in `layouts/admin.blade.php`.
